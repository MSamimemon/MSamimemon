### 🧾 Resume Assistant
A full-stack **MERN** application that brings resume management, job description tracking, ATS score analysis, and job application tracking into one connected workspace. Built with **React**, **Node.js**, **Express**, and **MongoDB Atlas**, with JWT-based authentication and resume parsing (PDF/DOCX). Deployed live with the frontend on **Vercel** and backend on **Render**.
